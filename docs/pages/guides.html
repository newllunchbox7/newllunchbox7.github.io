OSU!

Gear

Out of most of the rhythm games that will be covered here OSU! requires the least amount of gear.

To play OSU! you only need a couple of things:

1) A drawing tablet (or mouse)

2) A MECHANICAL or HALL EFFECT keyboard

3) A computer

aside from the computer these should be relatively cheap to get.

Tablets

When buying a tablet, in general you want one from Wacom as they are generaly higher quality than other brands (gaomon, huion, xp-pen, etc) though it doesn't matter a whole bunch.
but if you want suggestions or info on what tablets to buy you can use kuuube's tablet buying guide.

Keyboards

keyboards are a little bit easier to buy compared to a tablet. Almost any keyboard works. However if you end up with a membrane keyboard do note that it feels MUCH worse to play on. In general a mechanical keyboard is your best option. If you have a bit more money to spare though you can also get a hall effect keyboard which is the best performance wise.
if you want a bit more info before buying you can check the Public VSRG Keyboard Sheet.
although it's ment for VSRGs like OSU!Mania(<3) or Etterna, some of the information such as polling rate can be relevant for OSU!

Computer

Now OSU! is pretty lightweight compared to most modern games. To run OSU! (more specifically OSU!Lazer) you need a 64 bit computer with windows, mac, or linux(with appimage support) 8gb of ram (though you could play with less) and OpenGL2.1+ or DirectX 11. For storage it can take up anywhere from 1gb - 10gb (my install is about 10gb) for most users (though if you do want to horde beatmaps like a madman it could take up 80gb+)

Basic setup and things you should do before playing

So, you now have all the hardware that you need to play OSU! so now we will set up the game and some settings to make gameplay much better.

Installation

installing the game and going through the wizard

To install OSU! all you need to do is to navigate to osu.ppy.sh/home/download and hit big purple download button.

Once you have downloaded the installer, (or with linux the appimage,) run the installer and once the game finishes installing, launch the game.
Once you are in the game it will prompt you with the first-run setup. You should go through this and be sure to read EVERYTHING it tells you as it is important.

During the setup, make sure to install the tutorial. (you will NEED to play this in order to understand the game)

When the game prompts you with this login screen, hit register and go through the account creation.
THIS IS REQUIRED.
Without an account you will be restricted to LOCAL PLAY ONLY and will be UNABLE TO DOWNLOAD BEATMAPS except for the ones that install during the setup wizard.

Now that your settings are changed, you now get to download and try out some skins.
The easiest way to get skins is to go to skins.osuck.net Here you can find almost every OSU! skin. Look around and try to find one that looks good to you.

Once you find a skin you like, open the skin's page then head to the download tab. From there, it should give you multiple versions of the skin. (or sometimes only one) From there you will need to click on the download button that says "osk" (which is OSU!'s skin file) After you click it it will give you options on where to download the skin from. You can pick any of them. Once the .osk is done downloading, open your file manager and open it. (double click) It should automatically import into OSU!
